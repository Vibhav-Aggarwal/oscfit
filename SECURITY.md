# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within `oscfit`, please send an email to **Vibhav Aggarwal** at **vibhav.aggarwal2@gmail.com**.

Please include:
* A description of the issue.
* Steps to reproduce or proof-of-concept code.
* Potential impact.

We will acknowledge receipt within 48 hours and coordinate a fix and release before public disclosure.
